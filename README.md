Лабораторная работа №3. Вёрстка макета с помощью Flexbox и Grid

Тема: Языковой энтузиаст и переводчик Вариант: 17

Цель работы

Освоить Flexbox для одномерных макетов и CSS Grid для двумерных, а также принципы адаптивной вёрстки.

Реализованные возможности
Flexbox — навигация

Горизонтальное адаптивное меню <nav class="main-nav"> со ссылками на разделы страницы.

Экран	Поведение
Десктоп	Горизонтальный ряд ссылок, выровненный по центру
Мобильный (≤480px)	Превращается в вертикальный список
Flexbox — карточки «Изучаемые языки»

4 карточки (<article class="lang-card">), каждая содержит флаг, название языка и уровень владения.

css
.lang-card {
    flex: 0 1 calc(33.333% - 16px);
}

Адаптивность:

Ширина экрана	Карточек в ряд
Десктоп	3
Планшет (≤768px)	2
Мобильный (≤480px)	1
Grid — галерея «Фраза недели»

3 карточки-фразы (<article class="phrase-card">) на казахском, французском и английском языках. Внутри каждой карточки — три блока: фраза с аудио-иконкой, перевод, транскрипция.

css
.phrase-grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}

Адаптивность:

Ширина экрана	Колонок	Строк
Десктоп	3	1
Планшет (≤768px)	2	2
Мобильный (≤480px)	1	3
Семантика и доступность
<nav>, <article> - семантически верные теги для меню и карточек.
<button aria-label="..."> - для иконки воспроизведения аудио.
lang="kk", lang="fr", lang="en", lang="de" - атрибут языка на фразах и названиях языков.
